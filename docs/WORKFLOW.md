# Working workflow

This sequence grew out of the Agent Workflow Kit. Scale each stage to the impact, uncertainty, reversibility, and dependencies of the task. Apply it to software, research, and creative work using the checks appropriate to each deliverable.

## 1. Establish context

Identify the project, objective, existing artifacts, and relevant task decisions. Retrieve context for the current request and inspect the source when a claim matters. Check whether prior records still match the project state and recent user corrections.

## 2. Align on the goal

Write down why the work matters, who it serves, and what result would count as success. Resolve ambiguity that changes the result or the authority needed to proceed. Preserve open assumptions as such.

## 3. Plan the work

Choose a proportionate workflow. A narrow, reversible task can use a single agent and a targeted check. A broader change benefits from a short plan, bounded increments, and integration checks. Work with significant or hard-to-reverse effects needs failure analysis, recovery, and the relevant approval and review.

Link each consequential requirement to a check before execution. Replan when new evidence changes a dependency or acceptance criterion.

## 4. Assign and execute

Give each assignment an outcome, input snapshot, ownership, dependencies, editable scope, acceptance checks, and a stop condition. Use separate agents for work that can proceed independently. The integration owner reconciles conflicts and verifies the combined result. Roles, model choice, tool access, and workspace permissions are separate decisions.

Research assignments should define the question, source criteria, and expected evidence. Creative assignments should define the shared artistic constraints and account for shared assets, application instances, and compute. Implementation assignments should identify the relevant version and normal entry points.

## 5. Verify, hand off, and learn

Check the result against the intended outcome. Examples include executable acceptance checks, source-level citation review, and visual review against a reference. Record evidence with the input and output versions, applicable environment, observed result, and limits. Separate baseline failures from new regressions.

An interruption handoff should carry the current objective, dependencies, decisions, artifacts, completed checks, unresolved questions, and next action. On resume, reconcile the record with actual state before repeating an external action or reusing a dependent result. Keep durable lessons scoped and sourced. A later decision should explicitly supersede the older one.
