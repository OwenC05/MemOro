# Working in MemOro

Read [the scoping handoff](docs/HANDOFF.md) and [the project brief](docs/PROJECT-BRIEF.md) before substantial changes. Use [the working workflow](docs/WORKFLOW.md), [research register](docs/RESEARCH.md), and [benchmark proposal](docs/BENCHMARK.md) when evaluating a design.

- Establish the intended result, relevant project context, and observable acceptance criteria before committing to a design.
- Distinguish current behavior, published evidence, user decisions, and proposed experiments. Cite the source and record uncertainty where it affects a choice.
- Preserve an end-to-end single-agent baseline. Justify added retrieval, consolidation, delegation, or review with evidence from representative tasks.
- Match verification to the deliverable. Record the source snapshot and what a check actually confirms.
- Keep examples and fixtures public-safe. Use synthetic records for demonstrations that would otherwise need private histories, local credentials, or proprietary assets.
