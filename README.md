# MemOro

MemOro is a framework in design for carrying complex work across agent sessions, projects, and clients. A fresh agent should be able to recover current decisions, inspect their sources, resume unfinished work, and verify the result against the original goal.

The project grew out of the Agent Workflow Kit and an investigation into a local replacement for AgentMemory. It now covers storage and retrieval, memory consolidation, research tools, planning, implementation, delegation, and review. The first objective is to find which of these mechanisms improve real work across software, research, and creative production.
